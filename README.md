# Horas de Servicio Funval

Este proyecto es una aplicación web para el registro y control de horas de servicio, desarrollada por un equipo de trabajo colaborativo. La app busca mejorar la organización y visualización de la información relacionada con horas de trabajo y servicios realizados.

## Tecnologías utilizadas
- **JavaScript** (principalmente para la lógica de la app)
- **HTML / CSS** para la estructura y estilos
- **Tailwind CSS** para estilos responsivos
- **Vite** como bundler y entorno de desarrollo

## Estructura del proyecto
- `src/` → Contiene los componentes, hooks y archivos JS de la aplicación.
- `public/` → Imágenes, íconos y recursos públicos de la app.
- `team/` → Información de los miembros del equipo.
- `package.json` y `package-lock.json` → Dependencias del proyecto.
